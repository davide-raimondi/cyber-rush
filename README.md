# 🚀 Cyber Rush: Overdrive

> Arcade action-runner spaziale con sistema di potenziamento RPG, sviluppato in un singolo file HTML e ottimizzato per dispositivi mobile.

[![Gioca Ora](https://img.shields.io/badge/GIOCA%20ORA-Live%20su%20GitHub%20Pages-success?style=for-the-badge&logo=github)](https://davide-raimondi.github.io/cyber-rush/)

**Cyber Rush: Overdrive** combina l'azione frenetica di uno space-runner su tre corsie con meccaniche shooter ed elementi di progressione RPG. Progettato per offrire sessioni di gioco intense, fluide e immediate direttamente dal browser.

## ✨ Funzionalità Principali

- 🛸 **Movimento Tattico su 3 Corsie**: Schiva ostacoli, ottieni bonus per le schivate ravvicinate (near-miss) e abbatti droni e barriere distruttibili.
- 💥 **Boss Giganti & Super EMP**: Affronta boss di fine settore e attiva l'onda d'urto Super EMP per ripulire lo schermo nei momenti critici.
- 🔧 **Hangar & Progressione RPG**: Sblocca e potenzia navicelle e moduli tecnologici per personalizzare il tuo stile di gioco.
- 🚀 **Single-File Architecture**: Gioco completo racchiuso in un unico file HTML, CSS e JavaScript.

## 🛠 Tecnologie Utilizzate

- **HTML5 Canvas** per il rendering spaziale, il sistema particellare e gli effetti visivi.
- **CSS3** per l'interfaccia dell'hangar, gli HUD di gioco e il layout responsive.
- **Vanilla JavaScript (ES6+)** per la logica di gioco, il salvataggio dei progressi e la sintesi sonora tramite **Web Audio API**.
